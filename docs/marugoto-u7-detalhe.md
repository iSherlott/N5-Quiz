Meta comunicativa (Can-do): pedir para ir a um destino, perguntar como chegar, entender
instruções simples de direção, confirmar a parada e encerrar a interação com cortesia.
Sequência pedagógica: **Can-do → Vocabulário → Escrita/Leitura → Frase → Escuta → Role-play → Checkpoint**.

## B. Pontos gramaticais
- `〜まで` = até (destino final); `〜から` = ponto de partida.
- `て-form + ください` = instrução polida (行ってください, 曲がってください).
- Verbos de movimento (行きます／来ます／帰ります) e direções (右／左／まっすぐ).
- Estratégias de confirmação: repetir parte do pedido; `〜でいいですか` para confirmar.

## C. Frases-modelo (5, com variações)
1. 「藤沢までお願いします。」 → variação 「○○までお願いします。」
2. 「ここからどうやって行きますか。」 → 「駅までどうやって行きますか。」
3. 「まっすぐ行って、右に曲がってください。」 → trocar 右/左, ou 「二つ目の角で」
4. 「ここでお願いします。いくらですか。」
5. 「駅の近くですか。」 → 「近いですか／遠いですか」

## D. Roteiros de áudio (para gravação / TTS) — **Fase 2**
> Reprodução depende de áudio gravado ou `speechSynthesis` (TTS) offline — ainda **não
> implementado** (ver `trilha-arquitetura.md`, decisão pendente #3). Guardar como fonte do
> tipo de exercício `LISTEN_AND_TAP` quando a Fase 2 começar.

**Áudio 1 — Táxi (~40s):**
```
運転手:「どちらまでですか。」
乗客:「渋谷までお願いします。」
運転手:「わかりました。ここからまっすぐ行って、二つ目の交差点を右に曲がります。駅の近くです。」
乗客:「早い道でお願いします。」
運転手:「はい、わかりました。到着したらここで止めますか。」
乗客:「はい、ここでお願いします。いくらですか。」
運転手:「二千円です。ありがとうございました。」
```
**Áudio 2 — Pergunta na rua (~30s, detecção de palavras-alvo 駅/まっすぐ/右):**
```
「すみません、駅はどこですか。」
「この道をまっすぐ行って、右に曲がってください。」
「コンビニは交差点の近くです。」
「バス停はあの角にあります。」
「駐車場は遠いです。」
```
**Áudio 3 — Sequência de instruções (~45s, reconstrução das etapas):**
```
「まず、ここからまっすぐ行ってください。」
「次に、二つ目の角で左に曲がります。」
「そのまま進むと、右手にコンビニがあります。」
「コンビニの前で止めてください。」
```

## E. Role-plays (3 cenários)
1. **Táxi** (passageiro/motorista): pedir destino → confirmar rota → indicar parada → preço.
   - Base: 「渋谷までお願いします。」/「わかりました。まっすぐ行って、右に曲がります。」/「ここでお願いします。いくらですか。」
2. **Na rua** (pedir informação): 「すみません、駅はどこですか。」/「この道をまっすぐ行って、二つ目の角を左です。」
3. **Balcão/hotel**: 「公園に行きたいです。どうやって行きますか。」/「地下鉄で三駅です。出口を出て右です。」

## F. Checkpoint comunicativo (rubrica)
| Critério | Descrição | Pontos |
|---|---|---|
| Pedido do destino | 「〜までお願いします」 claro | 0–2 |
| Compreensão de instruções | segue 3 instruções (まっすぐ/右/左) | 0–3 |
| Confirmação da parada | 「ここでお願いします」 | 0–1 |
| Pergunta sobre preço | 「いくらですか？」 | 0–1 |
| Cortesia e pronúncia | すみません/お願いします/ありがとうございました | 0–3 |
| **Total** | | **0–10** |

Aprovação: **8–10 passa** · 5–7 precisa melhorar · 0–4 repetir.
